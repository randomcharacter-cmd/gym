# Images Directory

This directory is for storing optimized gym photos.

## Recommended Images

To get the best results, add these images:

1. **hero.jpg** (1920x1080px) - Main hero section background showing gym equipment or workout
2. **strength.jpg** (800x600px) - Strength training/weightlifting
3. **cardio.jpg** (800x600px) - Cardio/HIIT training
4. **personal.jpg** (800x600px) - Personal training session
5. **group.jpg** (800x600px) - Group fitness class
6. **crossfit.jpg** (800x600px) - CrossFit/functional training
7. **nutrition.jpg** (800x600px) - Nutrition coaching/healthy food

## Image Optimization Tips

For best performance:
- Use JPEG format with 80-85% quality
- Resize images to recommended dimensions before uploading
- Use tools like TinyJPG, ImageOptim, or Squoosh to compress
- Keep file sizes under 200KB per image

## Placeholder System

The website currently uses CSS gradients as placeholders. Simply add your images to this directory and they will automatically be used.
